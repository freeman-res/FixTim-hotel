# Автобусный датасет РФ — объединение реестра и Rossbus (25.10.2026)

**Основной результат:** `buses_full.csv` и `bus_calendar_30d.csv`.

## Файлы
- `buses_full.csv`: общая таблица объявленных поездок и отправлений из двух **независимых источников**. Поле `source` обязательно фильтровать. Прибытие для Rossbus отсутствует; для реестра дано только время (не дата) с неподтверждённым сопоставлением. Цены Rossbus относятся к **направлению**, не к конкретной строке поездки.
- `bus_calendar_30d.csv`: расчётные даты с 25.10 по 23.11.2026 на основе строгих правил дней недели. Дата **НЕ подтверждена**. Для Россбас включены только строки типа `ride`; для реестра — только однозначное расписание `круглогодично`, без «через день», сложных сезонных схем и т. п. При изменении расписания файл устареет. Повторы времени отправления могут обозначать несколько разных поездок и не удаляются без полного совпадения исходных полей.
- `rossbus_raw_buses.csv`: исходные 46 276 строк Rossbus, все сохранены как есть, в т. ч. полностью повторяющиеся записи.
- `rossbus_routes.csv`: 4 537 направлений Rossbus.
- `rossbus_departures.csv`: исходные 34 127 отдельных значений времени по направлению (не уникальные поездки).
- `source_route_matches_candidates.csv`: совпадения названий двух конечных городов между Rossbus и реестром; **не доказательство одного маршрута** и не основание автоматически подменять названия вокзалов/времена.
- `bus_routes.csv`, `bus_stops.csv`, `bus_departure_slots.csv`, `bus_connections.csv`: реестр межрегиональных маршрутов, маршрутные остановки с исходными расписаниями и потенциальные пары остановок.
- `city_connectivity.csv`, `cities.csv`: городская связность и справочник координат, **не автобусные рейсы**.
- `bus_price_reference.csv`: исторические/не датированные данные цен, источник без указанной лицензии.
- `rossbus_missing_routes.txt`, `rossbus_summary.txt`: исходная статистика и пропущенные направления.
- `summary_merged.json`: количественный аудит.
- Отдельно доступна `.sqlite` с исходными таблицами и новыми поисковыми таблицами.

## Самые важные ограничения
1. **Нет подтверждённых дат покупки:** поля `service_date_inferred` и `departure_datetime_origin_local` — прогноз по опубликованным дням недели, а не реальная доступность на дату. `schedule_date` у Rossbus НЕ трактуется как дата поездки; например, в источнике есть дата 19.10.2026 с расписанием «Вс», хотя 19 октября — понедельник.
2. **Отправление:** у Rossbus указан `from_station` — вокзал на странице направления (не доказано, что у каждого отдельного рейса ровно тот же вокзал). У реестра `from_stop` — конечный пункт зарегистрированного маршрута.
3. **Прибытие:** у Rossbus есть населённый пункт `to`, но НЕТ точного `to_station` или фактического времени прибытия. Для реестра `to_stop` известен, а `arrival_time_local_unverified_day` — предварительно сопоставлен по порядку отдельных слотов, без знания смещения по дням.
4. **Цены:** `price_from_rub`/`price_to_rub` у Rossbus — диапазон по **направлению** (не по конкретному времени), `trips_on_sale` — исторический снимок, **НЕ наличие на будущую дату**. Для реестра `price_from_rub` берётся из `reference_min_price_rub` (недатированное наблюдение) либо `fare_estimate_rub` (искусственная оценка по расстоянию и медиане цена/км), с явным `price_scope`; это **НЕ актуальная стоимость билета**. Перевозчики и расстояния реестра перенесены из `bus_routes.csv`.
5. **Отсутствие дубликатов:** из основной поисковой таблицы удалены только полностью идентичные строки исходного `buses.csv`. Рейсы с тем же временем и разной длительностью сохранены и не гарантированно отличаются физически.
6. **Дни и сезоны:** при календаризации не учтены праздничные отмены, изменения расписания, дополнительный сезонный сервис. Для реестра «через день» и неоднозначные правила оставлены только в исходных файлах.
7. **Часовые пояса:** местное отправление без IANA timezone, поэтому не рассчитана **дата прибытия** по длительности маршрута: между российскими регионами часы могут различаться.
8. **Покрытие:** реестр — только межрегиональные маршруты; Rossbus — неполный выборочный снимок сервиса (808 не подтверждены). Этого недостаточно для гарантии «все автобусы России» или live-бронирования.

## Пример поиска по конкретной дате (SQLite)
```python
import sqlite3
cx=sqlite3.connect('transport_dataset_2026_plus_rossbus.sqlite')
rows=cx.execute('''SELECT source, from_city, to_city, from_station, to_station,
   departure_datetime_origin_local, duration_min, price_from_rub, price_to_rub,
   calendar_date_status
   FROM bus_calendar_30d
   WHERE from_city = ? AND to_city = ? AND service_date_inferred = ?
   LIMIT 30''', ('Москва', 'Санкт-Петербург', '2026-10-30')).fetchall()
print(rows)
```
**Внимание:** результат поиска — гипотезы по расписанию, не доступные к продаже билеты. Перед показом конечного предложения нужно проверить дату, точную станцию, цену и наличие в официальном/билетном источнике.
