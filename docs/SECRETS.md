# Локальные секреты через age

`secrets.env.age` содержит зашифрованные `WEATHERBIT_KEY` и `WEATHERAPI_KEY`.
Открытого `secrets.env` в проекте нет. Публичный ключ для повторного шифрования
лежит в `age-recipient.txt`; закрытый ключ хранится только на этом ноутбуке:

`C:\Users\user\AppData\Local\ostrovok-hack\age-identity.txt`

После установки `age` откройте новый терминал и проверьте `age --version`.
На Windows для запуска приложения с ключами в памяти процесса:

```powershell
$env:AGE_IDENTITY_FILE = "$env:LOCALAPPDATA\ostrovok-hack\age-identity.txt"
python scripts/run_with_secrets.py -- python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

На Linux укажите путь к закрытому ключу через `AGE_IDENTITY_FILE` и запускайте
тот же `scripts/run_with_secrets.py` с командой сервера. Закрытый ключ **не
входит** в архив для развертывания и не должен попадать в Git или логи.
Скрипт расшифровывает секреты прямо в память и передаёт их дочернему процессу;
открытый файл на диске не создаётся.

Туту MCP не требует ключа в текущем клиенте. Его адрес, флаг и таймаут,
как и параметры РЖД, находятся в `.env.example` и не шифруются. `APP_PORT`
сейчас не является настройкой запуска: порт задаётся командой `uvicorn`.
Таймауты РЖД сохранены короткими, чтобы поиск не занимал весь лимит агента.

Текущая погода получается из Open-Meteo и климатического каталога без ключей.
Weatherbit/WeatherAPI пока не подключены; их шифрование готовит хранение на
случай последующего подключения. Поскольку значения ключей уже были отправлены
в переписке открытым текстом, перед рабочим использованием их следует заменить.
