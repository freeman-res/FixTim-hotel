# Живые цены и оценки

## Приоритет источников

1. При указанных датах приложение обращается к официальному [MCP Туту](https://mcp.tutu.ru/mcp): `search_avia`, `search_rail`, `search_hotels`.
2. Если пригодного авиапредложения нет, возвращается **оценка маршрута**, без рейса, расписания и ссылки на покупку.
3. Если пригодного предложения отеля нет, возвращаются реальные объекты локального каталога с **синтетической оценкой цены за ночь**. `price` и `total_price` остаются пустыми.
4. Если Туту не возвращает поезд, используется существующий провайдер РЖД. Синтетических поездов нет.

Расчётные суммы остаются во внутренних данных под полем `price_estimate`. Сайт показывает цену только для живого предложения и не выводит эти суммы как тариф.

## Откуда взяты ориентиры

- Городские средние цены: данные Ostrovok для бронирований мая–августа 2026 года, приведённые в [Коммерсанте](https://www.kommersant.ru/doc/8512243).
- Средние цены по регионам: данные TravelLine за январь–сентябрь 2026 года, приведённые в [Коммерсанте](https://www.kommersant.ru/doc/9041364).
- Для отеля используется городская средняя, затем региональная, затем средняя ближайшего опорного города до 120 км, затем общероссийский ориентир. Тип объекта, звёзды и подтверждённые удобства меняют оценку. Широкий диапазон отражает грубость модели.
- Авиаперелёт оценивается по географическому расстоянию (формула в `backend/app/catalog/pricing/estimates.py`). Это модельный ориентир без рыночной калибровки и без подтверждения, что маршрут продаётся.

## Обновление данных

После обновления `data/catalog/hotels.json`, `destinations.json` или `transport_options.json` запустить:

```powershell
.venv\Scripts\python.exe scripts\build_price_estimates.py
```

Генератор создаёт `data/catalog/hotel_price_estimates.json`, `flight_route_price_estimates.json` и `price_estimates_manifest.json`. Если файл оценок отсутствует или строка не совпадает с актуальным именем и городом отеля, оценка вычисляется из текущей записи каталога.

## Проверка

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe scripts\smoke_live_prices.py
```

Настройки: `TUTU_MCP_ENABLED`, `TUTU_MCP_URL`, `TUTU_MCP_TIMEOUT`. Для проверки только резерва можно задать `TUTU_MCP_ENABLED=false`. Внешний поиск требует точных дат и доступа к `https://mcp.tutu.ru/mcp` с проверкой TLS. Запросы передают Туту города, даты и число гостей/пассажиров.
