# Погода и климат

Архив `weather_package.zip` содержит Python-код и тесты, но не содержит готового
файла с погодными данными. Встроенный сервис использует координаты из
`data/catalog/destinations.json`.

- На ближайшие 16 дней: ежедневный прогноз Open-Meteo (температурный минимум,
  максимум и осадки). Кэш в памяти процесса на 30 минут. Если API недоступен,
  сервис не выдумывает прогноз.
- На более позднюю дату или при сбое API: среднемесячная температура и средние
  осадки за день из `data/catalog/climate.json`. Это **историческая климатическая
  справка**, а не прогноз на конкретную дату.
- В подборе направлений климат прикрепляется только если известен месяц поездки.
  В ответе агента тип `exact_forecast` отличается от `climate_estimate`.

Климатический файл строится из месячных климатических значений NASA POWER
(по текущему ответу API, 2001–2025 годы). Промежуточные результаты сохраняются
для возобновления после сетевой ошибки:

```powershell
.venv\Scripts\python.exe scripts\import_climate_nasa.py
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe scripts\smoke_weather.py
```

На Linux те же команды запускаются через `.venv/bin/python` и прямые слэши.
Для отключения запросов погоды установите `CATALOG_CLIMATE_ENABLED=0`.

Альтернативный импорт через 10 лет дневных данных Open-Meteo находится в
`scripts/import_climate_normals.py`, но бесплатный архивный API может вернуть
429 при массовой загрузке. Оба импорта пишут одинаковую структуру `climate.json`;
для целостности данных запускайте один из них, а не оба одновременно.

Исходная сезонная ветка из архива не включена: она трактовала абсолютную
температуру сезонной модели как аномалию и прибавляла её к норме. Это могло
удвоить ожидаемую температуру. Weatherbit и WeatherAPI из архива требуют
отдельных ключей; для текущей интеграции ключи не нужны.
