# Островок — сайт AI-агента

Сайт находится в `frontend/` и открывается через тот же FastAPI, что обслуживает API.

## Локальный запуск

Из корня проекта:

```powershell
.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000/`. В меню сайта реальный API выбран по умолчанию. Для автономного показа можно включить `Mock API`; это отдельный демонстрационный сценарий.

## Работа с API

- Свободный текст: `POST /api/v1/chat` с `message` и, после первого ответа, `session_id`.
- Выбор карточки: тот же endpoint с `action` (`select_destination`, `select_hotel`, `select_transport`) и `target_id`.
- История и условия поездки хранятся сервером по `session_id`.
- Цена отеля отображается только для живого предложения; остальные карточки остаются без цены.
- Цена транспорта отображается только для живого предложения.
- Корзина является учебной. Итог показывается, если все позиции имеют живые цены, и включает только дорогу туда и проживание.
- Подтверждённые демо-заказы сохраняются в истории только на этом устройстве. Историю можно открыть из вкладки или меню и очистить.

## Проверки

```powershell
node --test frontend\tests\*.test.mjs
.venv\Scripts\python.exe -m pytest -q
```

Браузерный тест находится в `tests/ui/smoke.mjs`; локальный тестовый API в `tests/ui/local_server.py` подменяет только модель, оставляя настоящий каталог и HTTP-приложение.

Для проверки на сервере см. `docs/SERVER_30_MIN.md`.
