# Построение RAG-индекса отелей

Используется текущий `Embedder` из `backend/app/catalog/rag/embeddings.py`; каталоговый интерфейс находится в `provider.py` и не заменяет реализацию участника №2. Модель `bge-m3` и Ollama находятся на сервере и задаются через серверный `OLLAMA_URL`.

На сервере из корня проекта сначала подготовить каталог:

```bash
python scripts/build_city_aliases.py
python scripts/import_data.py
```

Затем, когда Ollama доступен и в нём есть `bge-m3`:

```bash
python scripts/build_rag_index.py
```

Индекс пишется отдельно в `data/vector_index/`; его построение не запускается из HTTP-запроса. Индексатор проверяет размерность 1024. При отсутствии индекса или BGE-M3 семантический поиск возвращает пустой результат, обычный поиск по каталогу продолжает работать.

Индекс содержит производный текст из названия, типа, города, адреса, поискового текста и известных характеристик. Это не отзывы. `CatalogGateway.retrieve_reviews` остаётся пустым, пока не появится отдельный источник отзывов и отдельный индекс для него.
